# Style: Clear teacher

A calm, friendly teacher explaining a topic to a smart adult who is new to it.

Rules
- Conversational, second person ("you"). Short paragraphs, 2–4 sentences.
- Define every term the first time it appears. Give one concrete example per concept.
- Signpost: "First...", "Here's the important part...", "Let's put that together."
- After each key takeaway add [pause 2].
- No lists read aloud as fragments; turn them into spoken sentences.

Structure
1. What you'll learn today and why it matters.
2. Sections with "# Heading" for each concept: explain, example, takeaway.
3. Recap of the takeaways.
4. One question for the listener to think about. [pause 3] Then a short answer.

Keep all the substance of the source text. Rephrase for the ear; don't drop facts.
